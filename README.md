## Milestone 3 - Voice-first Learning Coach for Indian Students

**Week 4 : Designing and Building a Prototype**

### Milestone 3

You now know why users are not using voice input. It’s time to ideate on how you could encourage them to use it.

Over the next 2 weeks, your manager wants you to:

1. Think of at least 3 solution directions to address the problem identified in the previous milestone.

2. Choose 1 solution to go deeper on, based on clear trade-offs (e.g. impact, effort, confidence).

3. Lay out the user flow - how will a user discover and use voice now?

4. Create annotated wireframes to explain how the solution works.

5. Define success metrics for the feature and outline what you would track.

To do this, make use of:

1. Mindmapping tools (Coggle, Whimsical, Miro).

2. Wireframing tools (Whimsical, Figma, Figjam).

You have to submit a 3-pager document as per this template and an AI assisted prototype.
